# Google Maps Commercial & Non-Residential Parser

Browser-based Google Maps scraper using Selenium (no API key needed). Runs in Docker with an interactive wizard.

## Features
- **Исключение чистых жилых домов**: Дома, где нет никаких заведений и коммерции, автоматически отфильтровываются. В выборку попадают только реальные организации, магазины, кафе, услуги, аптеки, ПВЗ, офисы на первых этажах и отдельные здания компаний.
- **Несколько заведений на одном адресе**: Если в одном здании работают 3 магазина, кафе и пункт выдачи — каждый из них будет собран отдельной строкой со своим названием, категорией, телефоном и часами работы.
- **Radius up to 10 km**: Сеточный сканер делит область на перекрывающиеся ячейки (zoom 17) и сортирует их по расстоянию от центра к краям.
- **Scope selector (Режимы скопа)**:
  - **Режим 1 (Вся коммерция, заведения и организации)**: магазины, кафе, услуги, мебель, аптеки, пункты выдачи, офисы (чистые жилые дома исключаются) — *Рекомендуется*.
  - **Режим 2 (Только торговля и магазины)**: продукты, одежда, мебель, электроника, хозтовары.
  - **Режим 3 (Еда и общепит)**: кафе, рестораны, кофейни, пекарни, бары, фастфуд.
  - **Режим 4 (Все объекты)**: включая чистые жилые дома без фильтрации.
  - **Режим 5 (Пользовательский)**: ввод любых ключевых слов через запятую.
- **Многопоточность (Multi-threading)**: Запуск от 1 до 6 параллельных браузеров Chrome (по умолчанию 3). Ячейки сетки распределяются между независимыми воркерами через потокобезопасную очередь, что ускоряет сбор в 2.5–3.5 раза.
- **Преждевременная остановка (Ctrl+C)**: Нажмите `Ctrl+C` в любой момент — парсер немедленно остановится и сохранит в Excel всё, что успел собрать.
- **Автосохранение**: Каждые 25 новых точек и после каждой ячейки файл обновляется в `output/`.
- **Две дистанции**:
  - **Прямая дистанция (Straight-line)**: Точное геодезическое расстояние по формуле Haversine (для 100% точек).
  - **Пеший маршрут (Walking Route)**: Извлекается из маршрутизатора Google Maps (опционально).

## Quick Start

### Launch with Bash (Linux / macOS / Git Bash)
```bash
bash run.sh
```

### Launch with PowerShell (Windows)
```powershell
.\run.ps1
```

## Interactive Wizard Steps

1. **Origin coordinates**: Введите координаты через запятую (например: `64.56459,39.83801`).
2. **Search radius in km**: Радиус поиска от `0.1` до `10.0` км (например: `1.0` или `3.0`).
3. **Scope mode**:
   - `1` = **Вся коммерция, заведения и организации** (магазины, кафе, услуги, аптеки, ПВЗ, мебель, офисы; чистые дома отсекаются) — *Нажмите Enter*.
4. **Max places to collect**: Желаемое количество точек (от `1` до `50000`).
5. **Parallel browser threads**: Количество параллельных браузерных потоков (от `1` до `6`, по умолчанию `3`).
6. **Walking route distance**: Выберите `n` (рекомендуется для высокой скорости) или `y`.
7. **Excel filename**: Имя файла без расширения (сохраняется в папку `output/`).

> [!TIP]
> **Остановка в любой момент:** Нажмите **Ctrl+C**, чтобы прервать сбор и моментально получить Excel со всеми найденными на эту секунду точками.

## Output — Excel Columns

| Column | Description |
|---|---|
| **No** | Порядковый номер |
| **Name** | Название заведения / компании / магазина |
| **Address** | Точный адрес (улица, номер дома, этаж, офис) |
| **Phone** | Номер телефона |
| **Website** | Прямой сайт заведения (кликабельный) |
| **Hours** | График работы / статус (открыто, закрыто, круглосуточно) |
| **Rating** | Оценка Google (например: 4.8) |
| **Category** | Категория (магазин, кафе, аптека, услуги, мебель и т.д.) |
| **Latitude** | Широта |
| **Longitude** | Долгота |
| **Straight Distance (m)** | Точное расстояние от центра в метрах (сохраняется как число, в Excel отображается как `112 m`, сортируется математически) |
| **Walking Route** | Пеший маршрут Google Maps |
| **URL** | Ссылка на карточку Google Maps (кликабельная) |
